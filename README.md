# 🪨📄✂️ Jokenpo em TypeScript

Jogo de Pedra, Papel e Tesoura desenvolvido em TypeScript para praticar lógica de programação e os principais recursos da linguagem.

O projeto começou a partir da lógica de uma versão anterior desenvolvida em C e foi sendo adaptado e evoluído em TypeScript, chegando a uma versão mais estruturada, com tipagem, interfaces, sistema de pontuação e identificação personalizada do jogador.

## 🎮 Funcionalidades

- Cadastro do nome do avatar do jogador
- Escolha entre Pedra, Papel e Tesoura
- Jogada aleatória do computador
- Identificação de vitória, derrota ou empate
- Sistema de pontuação acumulativa
- Placar atualizado a cada rodada
- Opção de continuar ou encerrar o jogo
- Validação de jogadas inválidas

## 🛠️ Tecnologias

- TypeScript
- Node.js
- prompt-sync

## 🚀 Como executar

1. Clone o repositório
```bash
git clone <URL_DO_REPOSITORIO>
```

2. Instale as dependências
```bash
npm install
```

3. Execute o projeto
```bash
npx ts-node src/index.ts
```
